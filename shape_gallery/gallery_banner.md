# Gallery banner

`gallery_banner.png` is the text-free, 3072 x 1024 (3:1) banner displayed in the
main README. Every texture is generated by `MarbleGenerator` in
[`marble_circles.py`](../marble_circles.py). Pillow combines the textures into
six slanted panels with antialiased edges and fine dark separators.

## Regenerate

From the repository root, with the standard requirements installed:

```bash
python demo_banner.py --overwrite
```

Omit `--overwrite` to save a numbered copy, or pass `--output path/banner.png`.
The builder saves the banner, six original 1024 x 1024 textures in
`gallery_banner_textures/`, and all palette, seed, texture, rotation, and layout
settings in [`gallery_banner.json`](gallery_banner.json).

## Panels

| Palette | Renderer style | Seed | Rotation (degrees) |
| --- | --- | --- | --- |
| Midnight / cyan | Jupiter | 1207 | 90 |
| Teal / copper patina | Carrara | 505 | 0 |
| Amber / cream | Jupiter | 303 | 90 |
| Violet / lilac | Alien | 707 | 270 |
| Burgundy / coral | Jupiter | 1909 | 90 |
| Charcoal / ivory | Ice world | 818 | 270 |

Custom palettes and texture scales bring out different contours and flow in
the existing renderer. The composition only rotates, crops, and masks those
outputs; no AI-generated imagery is used. Seeds and settings live in
[`demo_banner.py`](../demo_banner.py), so the artwork can be rebuilt locally.

The original examples and `contact_sheet.png` remain available;
`demo_shapes.py` regenerates those independently of this banner.
